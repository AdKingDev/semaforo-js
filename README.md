# Semáforo Digital

Um semáforo digital desenvolvido com **HTML, CSS e JavaScript**, que simula o funcionamento de um semáforo real por meio da alternância automática entre as luzes verde, amarela e vermelha, com temporizadores e contagem regressiva.

## Sobre o projeto

O Semáforo Digital é um projeto desenvolvido para praticar conceitos fundamentais do desenvolvimento web, especialmente a manipulação do DOM, o controle de tempo e a alteração dinâmica de estilos utilizando JavaScript.

A aplicação reproduz um ciclo de sinalização visual, destacando a cor ativa, exibindo um emoji correspondente e informando o tempo restante para a próxima mudança.

## ✨ Funcionalidades

- 🚗 **Alternância automática:** mudança entre as luzes verde, amarela e vermelha.
- ⏱️ **Contagem regressiva:** exibição do tempo restante de cada etapa.
- 💡 **Efeitos visuais:** alteração das cores e aplicação de efeitos de brilho na luz ativa.
- 🚦 **Indicadores visuais:** emojis que representam cada situação do semáforo.
- 🔄 **Ciclo contínuo:** repetição automática da sequência de sinalização.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação dos elementos da página.
- **CSS3:** estilização do semáforo, layout e efeitos visuais.
- **JavaScript:** controle da sequência, temporizadores, contagem regressiva e manipulação do DOM.

## ⏱️ Tempo de cada sinal

| Sinal | Duração |
|---|---:|
| 🟢 Verde | 5 segundos |
| 🟡 Amarelo | 3 segundos |
| 🔴 Vermelho | 5 segundos |
| 🟡 Amarelo | 3 segundos |

Após a sequência, o semáforo retorna à luz verde e reinicia o ciclo.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos importantes de JavaScript e desenvolvimento web:

- Seleção de elementos com `document.querySelector()`.
- Manipulação de classes com `classList.add()` e `classList.remove()`.
- Alteração dinâmica de estilos CSS com JavaScript.
- Uso de `setTimeout()` para controlar a duração de cada sinal.
- Uso de `setInterval()` para implementar a contagem regressiva.
- Criação e chamada de funções para organizar o comportamento da aplicação.
- Manipulação do conteúdo HTML por meio de `innerHTML`.
